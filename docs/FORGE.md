Name: Brainiac Weekend Collections

GUID: project.brainiac.weekendcollections

Teaser:
3 collections, 30 items and a permanent +10% GP bonus per completed set.

Description:
Adds 3 collections to WeekendDrops using 30 items from the required item mod. Complete a set to earn a permanent +10% GP bonus on Weekend rewards. Completing all sets in this addon gives +30%.

Includes English, German, Russian, Brazilian Portuguese and Simplified Chinese. Extract the ZIP into your SPT game folder, then restart the server and game. Every player needs the included client plugin.

Requires SPT 4.1.6, WeekendDrops 1.0.7 and the item mod listed in the README. The addon contains no item models or textures.
