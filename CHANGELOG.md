# Changelog

## 1.2.1 — 2026-10-16

- Added collection names, descriptions and milestones for all 17 Weekend Drops Continued language codes.
- Added Japanese, Korean, French, Spanish, Latin American Spanish, Polish, Czech, Italian, Hungarian, Romanian, Slovak and Turkish.
- Recognize native game codes and common regional/ISO aliases, with English fallback.
- Retain the same three collections, item IDs, saved progress and permanent +10% GP bonus per set.

## 1.2.0

- Completion bonuses increased from 2% to 10% per collection.
- Existing collections receive the updated bonus without resetting donations.

## 1.1.0

- Collection names, descriptions and milestones in five languages.
- Client-side language selection for each player.
- English fallback instead of Portuguese-only collection text.
- Includes a client plugin; install it on every player’s game.


## 1.0.0

- Three collections of ten items.
- In-memory integration without replacing Weekend's configuration.
- Existing collections preserved and duplicate-free reloads.
- Distributed separately from the item mod.
